# 🥒 삼투압 실생활 탐색기

WAVE 프로그램(광명시 대학생 멘토단) 삼투압 실험 데이터를 파이썬으로 분석하고 웹앱으로 만든 프로젝트입니다.

## 🔬 프로젝트 소개

3종 채소(무·오이·배추)를 6가지 소금 농도에 담그고 질량 변화를 측정한 실험 데이터를 Streamlit 웹앱으로 시각화·시뮬레이션합니다.

## 🚀 실행 방법

### 로컬에서 실행

```bash
pip install -r requirements.txt
streamlit run app.py
```

### Streamlit Cloud 배포

이 저장소를 [Streamlit Cloud](https://share.streamlit.io)에 연결하면 자동 배포됩니다.

## 📊 기능

- **채소별 분석**: 회귀 그래프와 등장액 농도 확인
- **삼투 시뮬레이터**: 채소·농도 입력으로 예상 결과 계산
- **채소 비교**: 3종 채소 특성 비교
- **실생활 응용**: 요리·의학·자연·저장 사례
